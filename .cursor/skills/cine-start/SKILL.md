# Start session

1. Read `project.yaml` and `docs/launch/SESSION_HANDOVER_TO_NEW_CHAT.md`.
2. If the task is rules/engine → `cine-core`. Content catalog → `cine-content`. Visual/haptics → `cine-feel`. Rooms/auth/RLS → `cine-multiplayer`. Store/Capacitor → `cine-ship`.
3. Restate: product (Cine-XOX), current slice from `docs/product/MVP.md`, files you will touch, files you will not touch.
4. If the slice is the next line in `MVP.md`, do it. Ask only when the slice is ambiguous.

Do not dump the full spec into chat. Cite sections by name.
